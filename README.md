# 🎮 Hazel-Eight — Interactive JavaScript Game

A simple JavaScript task turned into a browser game through creativity, experimentation, and continuous improvement.

**Hazel-Eight** is an interactive browser game built with HTML, CSS, and vanilla JavaScript. What started as a bouncing-button challenge evolved into a game with multiple gameplay phases, dynamic movement, time-based challenges, rewards, and persistent high scores.

🌐 **Live Demo:** [Play Hazel-Eight](https://java-script-hazel-eight.vercel.app/)

## ✨ Features

- **5 Gameplay Phases** — Progress through phases with increasing difficulty.
- **Cursor-Aware Movement** — Interactive movement logic that responds to cursor position.
- **Dynamic Difficulty** — Speed and behavior change as the game progresses.
- **Timer-Based Challenges** — Complete challenges within a limited time.
- **Daily Rewards & Streaks** — Track daily rewards and maintain activity streaks.
- **Persistent High Scores** — Save high scores using browser LocalStorage.
- **Interactive Animations** — Visual effects and feedback for a more engaging experience.
- **Dark Brutalist UI** — A bold black-and-white interface with electric-yellow accents.

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Game structure |
| CSS3 | Styling, layouts, and animations |
| JavaScript | Game logic, interactions, and state management |
| LocalStorage | Persisting scores and game-related data |

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. No backend or package installation is required.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/BeautyMauryaa/Hazel-Eight.git
   ```

2. Open the project folder:

   ```bash
   cd Hazel-Eight
   ```

3. Open `index.html` in your browser.

Alternatively, use the **Live Demo** link above to play the game directly.
